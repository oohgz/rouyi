# 截图清单

把截图放到本目录，**按下列文件名命名**，README 会自动显示。

| 文件名 | 截图内容 | 要点 |
| --- | --- | --- |
| `01-login.png` | 登录页 | 页面整洁、无报错 |
| `02-score.png` | 成绩管理列表 | 有数据、显示筛选条件 |
| `03-selection.png` | 选课管理列表 | 显示学生与课程关联 |
| `04-chart.png` | 成绩分数段统计 | ECharts 环形图 + 三维筛选 |
| `05-teacher-scope.png` | 教师视角的学生列表 | 只出现本人课程学生 |
| `06-forbidden.png` | 越权拦截提示 | 如「无权查询该课程的学生」 |
| `07-swagger.png` | 接口文档 | `/swagger-ui/index.html` |
| `08-dashboard.png` | 首页/概览 | 体现系统完整度 |

建议：

- 分辨率 ≥ 1280×720，浏览器缩放 100%
- 不要包含真实姓名、学号、手机号，用测试数据截图
- 可用 Win + Shift + S 截图后直接保存到本目录
