# 接口自测记录

> 说明：本文档记录开发过程中对接口的自测验证，覆盖正常流程、权限越权、异常返回与边界值四类场景。
> 自测工具：Postman（多角色环境 + 请求集合）；日志排查：Linux `grep/tail` + 后端异常日志。

## 一、测试环境

| 项 | 内容 |
| --- | --- |
| 后端 | 本地 Spring Boot，`http://localhost:8080` |
| 数据库 | MySQL 8.0，库名 `smart_course_management` |
| 缓存 | Redis，`localhost:6379`（无密码） |
| 账号 | admin / manage / teacher（2 个，分属不同课程）/ student |
| 鉴权 | 请求头 `Authorization: Bearer <token>` |

## 二、用例清单

| F-02 | 登录 | 错误密码登录 | 返回业务错误提示，不返回 token | 通过 |
| F-03 | 学生 | 新增学生并关联系统用户 | 新增成功，列表可查 | 通过 |
| F-04 | 课程 | 为课程绑定授课教师 | 课程列表显示授课教师 | 通过 |
| F-05 | 选课 | 学生选课 | 选课记录新增，课程余量变化 | 通过 |
| F-06 | 成绩 | 教师录入成绩 | 成绩保存且学生可查到本人成绩 | 通过 |

### 2. 权限与越权类（重点）

| 编号 | 场景 | 操作 | 预期结果 | 结论 |
| --- | --- | --- | --- | --- |
| P-01 | 教师跨课程查学生 | 教师 A 用自身 token 调 `/manage/student/listByCourse/{教师B的courseId}` | 返回「无权查询该课程的学生」 | 通过 |
| P-02 | 教师无授课 | 教师账号未绑定任何课程时查询选课列表 | 返回空集合，**不返回全量数据** | 通过 |
| P-03 | 学生看他人成绩 | 学生 A 调成绩列表接口 | 仅返回本人成绩 | 通过 |
| P-04 | 未登录访问 | 不携带 token 调业务接口 | 返回 401 / 未授权提示 | 通过 |
| P-05 | 角色越权 | 学生 token 调管理员接口 | 返回无权限提示 | 通过 |
| P-06 | 前端绕过 | 直接调接口而非通过页面按钮 | 服务端仍拦截，不依赖前端隐藏 | 通过 |
| P-07 | 教师看全部学生 | 教师调学生列表 | 仅返回本人课程下的学生 | 通过 |

### 3. 异常与边界类

| 编号 | 场景 | 预期结果 | 结论 |
| --- | --- | --- | --- |
| E-01 | 不存在的 id 查询详情 | 返回业务错误提示，不抛 500 堆栈 | 通过 |
| E-02 | 必填参数缺失 | 参数校验失败提示 | 通过 |
| E-03 | 成绩超出 0–100 范围 | 校验拦截或明确提示 | 通过 |
| E-04 | 重复选同一门课 | 返回「已选」提示，不产生重复记录 | 通过 |
| E-05 | 超长字符串写入 | 提示长度超限，不写库 | 通过 |

## 三、自测中发现并修复的问题

| # | 问题 | 现象 | 原因 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | 权限过滤导致分页失效 | 教师查询第 2 页，返回与第 1 页相同数据 | 角色校验中的查询消耗了 `PageHelper.startPage()` | 权限过滤后按 `pageNum/pageSize` 重新分页 |
| 2 | 教师未授课时返回全量 | 新教师账号能看到所有选课 | 授课课程集合为空时未短路，查询条件失效 | 空集合直接返回 `emptyList()` |
| 3 | 异常堆栈外泄 | 接口报错返回原始堆栈 | 未统一异常处理 | 全局异常拦截，统一业务提示 |
| 4 | 跨课程取数 | 教师 A 可查教师 B 课程学生 | 接口未校验资源归属 | 增加 `course.teacherId` 与登录教师比对 |

## 四、回归方式

1. Postman 按角色分 4 套环境（admin / manage / teacher / student），各自保存 token 变量；
2. Collection 内按模块分组，逐接口配置断言：HTTP 状态码、业务 `code`、关键字段非空、返回条数；
3. 修改代码后整包执行一遍，确认原有用例不回归。
